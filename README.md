# Electric-Vehicles-Market-Size-Analysis-for-Washington-State-in-USA

https://lookerstudio.google.com/s/uSHj4zELtgI

🔹 Project Overview

Analyzed Electric Vehicle (EV) adoption trends in Washington State to estimate market size, identify growth patterns, and generate actionable insights. The project demonstrates data cleaning, exploratory analysis, and visualization skills using Python.

🚀 Key Highlights

Cleaned and processed real-world EV registration datasets.

Conducted exploratory data analysis to uncover trends by year and county.

Estimated market size and adoption growth patterns.

Created interactive and insightful visualizations to communicate findings.

🛠 Tools & Technologies

Python (Pandas, Matplotlib, Seaborn)

Jupyter Notebooks

Data visualization & exploratory analysis
